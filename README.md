## Project Overview
As an AI Program Manager and Software Engineer, I developed **Royal Rescue** to explore the intersection of game development and complex AI behavior. This project showcases the implementation of autonomous NPCs (Non-Player Characters) capable of decision-making and pathfinding within a dynamic environment.

## Key Features & Product Highlights
* **Intelligent NPC Behavior:** Implemented Finite State Machines (FSM) to give characters realistic states (e.g., Patrol, Chase, Attack).
* **Pathfinding & Navigation:** Algorithms enabling smooth and logical movement across complex terrains.
* **Game Logic & Physics:** Developed in C# utilizing Unity's physics engine for realistic interactions.
